# PCI-1716 series hardware specification

Source: Advantech, [*PCI-1716/1716H/1716L User Manual*, Edition 2, May 2025](https://advdownload.advantech.com/productfile/Downloadfile1/1-33HO84K/PCI-1716_Series_User_Manual_Ed.2_FINAL.pdf). Page numbers below are the **printed manual pages**, not PDF viewer page numbers. This is a paraphrased engineering reference; consult the linked manual, especially Figure 2.2, before wiring the card.

## Models and architecture

| Model | Maximum AI conversion rate | Analog outputs | Shared functions |
| --- | ---: | ---: | --- |
| PCI-1716 | 250 kS/s | 2 | 16 AI terminals, 16 DI, 16 DO, one counter |
| PCI-1716H | 1 MS/s | 2 | Same channel counts |
| PCI-1716L | 250 kS/s | None | Same AI, DI, DO and counter counts |

The card has a **single multiplexed 16-bit ADC**. Its AI conversion clock rate is shared by every channel in the scan, so the listed maximum is **not** a per-channel rate. For a scan of *N* measured inputs at a uniform conversion clock, each input is sampled approximately once per *N* conversions. The card provides automatic channel/gain scanning, an 8,192-sample AI FIFO, and a PCI Universal interface. [Manual pp. 2, 13–14, 47, 51.](https://advdownload.advantech.com/productfile/Downloadfile1/1-33HO84K/PCI-1716_Series_User_Manual_Ed.2_FINAL.pdf)

## Analog input

| Property | Specification |
| --- | --- |
| Input arrangements | 16 single-ended inputs, 8 differential inputs, or a mixture by adjacent pair |
| Resolution | 16 bits |
| Input ranges | Bipolar: ±10, ±5, ±2.5, ±1.25, ±0.625 V. Unipolar: 0–10, 0–5, 0–2.5, 0–1.25 V |
| Range selection | Software selectable per channel via the programmable gain amplifier |
| Conversion clock | Internal or external; model-dependent maximum above |
| AI FIFO | 8,192 samples shared by enabled channels |
| Input impedance | 100 MΩ typical |
| Maximum input voltage / common-mode range | ±11 V / ±11 V |
| Overvoltage protection | ±15 V |
| Linearity | INL and DNL each ±1 LSB maximum |
| PGA −3 dB bandwidth | 4 MHz at ±10/±5 V (and 0–10 V); 2 MHz at ±2.5 V (0–5 V); 1.5 MHz at ±1.25 V (0–2.5 V); 0.65 MHz at ±0.625 V (0–1.25 V) |

The manual lists idle-channel noise of 261 µV RMS and AC performance of 82 dB SNR, −81 dB THD, −78 dB THD+N, 84 dB SFDR and 12.73 effective bits. Its absolute-accuracy figures depend on range and temperature relative to the last automatic calibration; refer to the original table before assigning an error budget. [Manual pp. 14, 47.](https://advdownload.advantech.com/productfile/Downloadfile1/1-33HO84K/PCI-1716_Series_User_Manual_Ed.2_FINAL.pdf)

The hardware supports instant software-timed reads and buffered hardware-timed acquisition. Buffered AI may acquire a finite post-trigger record or stream until stopped; the samples move through onboard FIFO and DMA to host memory. The scan visits selected channels in channel-number order. [Manual pp. 14, 22–24.](https://advdownload.advantech.com/productfile/Downloadfile1/1-33HO84K/PCI-1716_Series_User_Manual_Ed.2_FINAL.pdf)

### Wiring and grounding

| Input configuration | Physical connection | Occupied AI terminals |
| --- | --- | --- |
| Single-ended | Sensor signal to `AIx`; sensor return to `AGND` | One |
| Differential | Sensor positive to even `AIx`; sensor negative to next odd `AI(x+1)` | Two; for example AI0/AI1 or AI8/AI9 |

An odd terminal that is the negative leg of a differential pair is not a second independent sensor input. The manual says selecting differential on the even channel also fixes its odd partner to differential. A grounded source is best measured differentially to reduce ground-loop noise. A floating source can use either arrangement, but a floating differential source may need a DC bias path to AGND to keep common-mode voltage within range. The manual describes equal-value bias resistors (typically 10–100 kΩ for a low-impedance source) and warns that their loading can attenuate the measured signal. Use shielded cable for external wiring. [Manual pp. iii, 13–15.](https://advdownload.advantech.com/productfile/Downloadfile1/1-33HO84K/PCI-1716_Series_User_Manual_Ed.2_FINAL.pdf)

## Analog output (PCI-1716 and PCI-1716H only)

Two single-ended, 16-bit voltage outputs are available; PCI-1716L has no AO function. Internal-reference output ranges are ±10, ±5, 0–10 and 0–5 V. External reference permits ±VREF or 0–VREF; externally referenced output is not calibrated automatically. Maximum update rate is 1 MS/s **per output channel**, with internal or external update clock and an 8,192-sample buffer shared by enabled outputs. Maximum drive is ±20 mA; output impedance is at most 0.1 Ω. The specified power-on state is 0 V in the ±10 V range, with a specified 30 mV, 10 ms power-on glitch. Connect the load between `AOx_OUT` and `AGND`. [Manual pp. 16, 48.](https://advdownload.advantech.com/productfile/Downloadfile1/1-33HO84K/PCI-1716_Series_User_Manual_Ed.2_FINAL.pdf)

| AO signal | Pin | AO signal | Pin |
| --- | ---: | --- | ---: |
| AO0_REF | 59 | AO1_REF | 25 |
| AO0_OUT | 58 | AO1_OUT | 24 |

[Manual p. 11, Figure 2.2.](https://advdownload.advantech.com/productfile/Downloadfile1/1-33HO84K/PCI-1716_Series_User_Manual_Ed.2_FINAL.pdf)

## Digital I/O and counter

| Function | Specification |
| --- | --- |
| Digital input | 16 channels in two ports; 5 V TTL; high ≥2.0 V, low ≤0.8 V; 10 kΩ pull-up; maximum 1 MS/s buffered sample rate; 4,096-sample buffer |
| DI features | Rising/falling/both-edge interrupt, port pattern match, state latch, 25 ns–105 ms debounce |
| Digital output | 16 channels in two ports; 5 V TTL; maximum 1 MS/s buffered update rate; 4,096-sample buffer; 8 mA maximum per channel and 20 mA summed per port |
| Counter | One 32-bit, 5 V TTL counter; event counting to 10 MHz, 0.1 Hz–10 MHz frequency measurement, one-shot and timer/pulse modes; timer timebase 40 MHz |

DI and counter input working range is −0.25 to +5.25 V, with protection specified from −0.5 to +6.5 V. For DI, DO and counter wiring, use `DGND` as the reference. [Manual pp. 17–20, 49–50.](https://advdownload.advantech.com/productfile/Downloadfile1/1-33HO84K/PCI-1716_Series_User_Manual_Ed.2_FINAL.pdf)

The connector assigns DI0–DI15 to pins **56–49 (even channels)** and **22–15 (odd channels)**, and DO0–DO15 to **47–40 (even channels)** and **13–6 (odd channels)**, descending in channel order. `DGND` appears on pins **48, 14, 39 and 5**. Check Figure 2.2 for an individual channel before terminating a wire. [Manual p. 11, Figure 2.2.](https://advdownload.advantech.com/productfile/Downloadfile1/1-33HO84K/PCI-1716_Series_User_Manual_Ed.2_FINAL.pdf)

## External clock and triggers

`ECLK_IN` can supply the conversion/sample/update clock for supported functions; `ECLK_OUT` exposes the AI conversion clock for synchronizing devices. The external clock input is 5 V TTL, rising-edge triggered, with a 100 ns minimum pulse width. `ECLK_GATE` is a 5 V TTL gate. The manual describes software or hardware start/stop triggers for buffered AI streaming. [Manual pp. 12, 23–24, 50–51.](https://advdownload.advantech.com/productfile/Downloadfile1/1-33HO84K/PCI-1716_Series_User_Manual_Ed.2_FINAL.pdf)

**Manual inconsistency:** the prose on printed p. 24 says the external conversion clock is effective when the gate is low and masked when high, while the specification on printed p. 51 labels the gate polarity “Low level pause.” These imply opposite active levels. Verify gate behavior on the target card and DAQNavi configuration before relying on it. [Manual pp. 24, 51.](https://advdownload.advantech.com/productfile/Downloadfile1/1-33HO84K/PCI-1716_Series_User_Manual_Ed.2_FINAL.pdf)

## Installation and operating limits

| Item | Specification |
| --- | --- |
| Host interface and connector | PCI Universal card; 68-pin SCSI I/O connector |
| Card power draw | +5 V: 500 mA typical, 800 mA maximum; +12 V: 150 mA typical, 400 mA maximum |
| Connector supply outputs | +5 V ±5% at 200 mA maximum (pin 1); +12 V ±5% at 100 mA maximum (pin 35), referenced to DGND |
| Size and mass | 175 × 100 × 18 mm; 108 g |
| Operating conditions | 0–60 °C, 10–90% RH, non-condensing |
| Storage conditions | −20–70 °C, 5–95% RH, non-condensing |

The PCI bus assigns card resources automatically. A four-position Board ID DIP switch selects IDs 0–15; the default is 0. Disconnect chassis power before installing, moving jumpers or changing wiring. Shielded 68-pin cables and compatible wiring boards are listed in the manual. The manual calls the Board ID switch **SW1** in its section heading and prose but **SW2** in Table 2.1; inspect the actual board silkscreen rather than relying on the table label. JP1 controls the post-hot-reset output state and defaults to the default-state position. [Manual pp. iii, 2, 5, 8–11, 51.](https://advdownload.advantech.com/productfile/Downloadfile1/1-33HO84K/PCI-1716_Series_User_Manual_Ed.2_FINAL.pdf)

## Implications for IIoT-data-ingestion

The points below describe the **current repository implementation**, not capabilities guaranteed by the hardware manual.

- The Config Center's sensor rows map `AI0`–`AI15` to physical analog input terminals. Its PCI-1716-specific validation reserves the following odd channel when an even channel is differential, and rejects pseudo differential. See [`app.js`](../../services/daq_navi/web/static/config_center/app.js) and [`production_acquisition.py`](../../services/daq_navi/core/production_acquisition.py). The even/odd pairing comes from manual pp. 12–14.
- The UI currently offers a generic `−12 to +12 V` range. That range is **absent** from the PCI-1716 series input-range table on manual p. 47; do not select it for this card. The UI also exposes only a subset of the card's narrower ranges. See [`app.js`](../../services/daq_navi/web/static/config_center/app.js).
- The production acquisition adapter passes configured signal type and voltage range to DAQNavi, and omits configuration of an odd negative leg reserved by a differential pair. See [`production_acquisition.py`](../../services/daq_navi/core/production_acquisition.py).
- The Config Center currently labels `CLOCK_RATE` as a **per-channel** rate and accepts 1,000–2,000 Hz. The adapter assigns that number to DAQNavi `conversion.clockRate`. The manual describes this as a **conversion clock shared across enabled inputs**, so the per-channel label should not be treated as a hardware guarantee; confirm the actual time between samples on each channel before using it to calculate sensor sample rates. See [`app.js`](../../services/daq_navi/web/static/config_center/app.js), [`production_acquisition.py`](../../services/daq_navi/core/production_acquisition.py), and manual pp. 14, 47.
